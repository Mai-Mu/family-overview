# 家庭一览实现设计

## 页面

浅色背景、深绿导航、清晰卡片与少量青绿色强调。桌面侧栏按“家庭安排”和“家底资料”分组；窄屏收起导航。总览展示按币种区分的已录资产、已录负债、规则折算月度收入和支出，提供首次整理入口和最近更新。

八个模块采用清单加右侧详情面板，支持搜索、按成员和状态筛选、查看已移除记录。重点事项用分区表单；其他模块由字段定义生成常用项、展开项及通用资料区。全部字段可留空。详情显示保存状态、修改历史及附件。

未保存时离开详情，使用页面内对话框确认。浏览器本地临时缓存最近一份未保存内容，刷新后恢复；文件对象不缓存，附件需要重新选择。临时草稿不替代SQLite保存和ZIP备份。保存期间锁定详情操作，避免同时编辑或关闭导致显示状态错乱。

## 运行方式

Python标准库提供本机HTTP服务、SQLite访问、上传和备份。前端采用原生HTML、CSS、JavaScript，无第三方运行时依赖。绑定127.0.0.1，默认端口8765，不自动发布。业务字段定义由`design/家庭经济信息收集字段定义.json`加载。

## SQLite

`records`存储模块、UUID、可空业务字段JSON、版本、创建修改及移除时间。金额在JSON中保存为十进制文本，使用Decimal做统计，空白保存为null。`record_links`、`allocations`提供多成员、记录关联和选填分担的结构化索引。`history`保留每次保存的版本快照。`attachments`保存关联、文件名、类型、大小和存放路径，文件放在`data/uploads`。

技术主键与系统时间不需要用户填写。每次写入在事务内更新正文、关联索引、分担和历史；版本检查防止覆盖其他窗口的新保存。删除为软删除，附件与历史保留，可恢复。

## 金额与关联

只统计已提供且可理解的金额，不把缺失当零。单值与范围保持原口径，不同币种独立。资产汇总反映已录盘点值；共同资产在个人视图单列，不默认分摊。定期收支按已生效规则和频率折算月度参考，不是实际流水或逐日预测；缺少必要信息的规则显示在待补充计数中。

贷款概况可直接展开关联家庭事项的付款进度，填写时自动建立关联，无需重复登记。贷款或保单可生成定期规则的预填草稿；只有用户保存后才生效，缺失信息保持空白。未来收支只汇总规则，不再重复加贷款月供、保费或事项总额。

## 文件与备份

上传文件使用独立生成的存储名，原名称仅用于展示和下载。页面不执行上传内容。备份包含一致性SQLite快照、附件、结构化记录和字段定义。应用只提供当前静态页面和明确的设计文档，不把整个工作目录开放为文件服务。

数据库、附件和备份没有应用级加密或登录。仅监听本机，不提供云端同步；依靠操作系统账户控制文件访问。ZIP恢复采用停服后替换数据目录的方式，步骤见README。

## 验证

使用临时SQLite运行持久化、空白与零金额、金额区间、跨币种、共同归属、内部转账、重复关联、版本冲突、附件和ZIP备份检查。再在浏览器验证新增、保存、刷新、筛选和窄屏布局。实际家庭数据不用于测试。
